# Python Game Engine Wrapper

A low-level 2D game engine wrapper and game building module built 
in Python with Tkinter — designed to be more powerful and flexible 
than Turtle while remaining lightweight and accessible.

## Why This Exists
Unlike Turtle, this engine supports multiple simultaneous windows 
that can communicate with each other — enabling more complex, 
multi-panel game architectures out of the box.

## Features
- Delta Time support for frame-rate independent movement
- Modular object system — Text, TextClickable, and more
- HTML-style font system with custom font adding support
- Full Tkinter Canvas customization — barriers, cursor editor
- Built-in game mathematics — Clamp, Switch, Lerp, RoundTo
- Full keyboard input by default (similar to Pygame)
- Built-in Timer class
- Side panels for Tkinter widgets
- Multi-window support with inter-window communication

## Status
Actively in development — ongoing improvements to architecture,
features, and documentation.
